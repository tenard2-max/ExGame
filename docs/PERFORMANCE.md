# 성능·호환성 기준

## 불변식

- 활성 청크는 항상 **최대 25개(5×5)** 입니다.
- 원본 지형은 저장하지 않고 Seed로 재계산합니다.
- 청크는 미리 생성하지 않습니다.

## 목표 기준 (PC 브라우저)

| 항목 | 목표 |
|------|------|
| FPS | 60 유지 (일반 플레이) |
| 활성 청크 | ≤ 9 |
| Draw call | 디버그 오버레이 포함 대략 40 이하 |
| 입력 | 키보드·마우스·터치 동일 제스처 |

## 적용한 최적화

- 청크 단위 Graphics 렌더링, 같은 색상 도형 배치(batch fill)
- HUD는 카메라 추적 노드로 화면 고정 (월드 재생성과 분리)
- 청크 변경 시에만 해당 청크 노드를 재생성
- IndexedDB에는 delta·플레이어 상태만 저장

## 브라우저 호환

- 1순위: Chromium 계열 (Chrome, Edge) 최신 버전
- 2순위: Firefox 최신 버전
- 필수 API: WebGL, IndexedDB, ES2020 수준 JS
- 모바일: 입력·해상도(`SHOW_ALL`)·터치 핫바/세이브 버튼 대응
- 오프라인: 로컬 정적 파일 + IndexedDB (네트워크 불필요)

## 수동 확인 체크리스트

- [ ] 장시간 이동해도 `loadedChunkCount`가 9를 넘지 않는다
- [ ] 핫바 슬롯을 터치/클릭으로 선택할 수 있다
- [ ] 세이브 버튼을 터치/클릭으로 누를 수 있다
- [ ] HUD 탭이 월드 채굴로 잘못 들어가지 않는다
- [ ] 저장→새로고침→복원 후에도 60FPS 근처를 유지한다
