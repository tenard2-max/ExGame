# ExGame 타일 원칙

지형 미관과 생성 불변식을 정의합니다. 청크는 **로드·저장 단위**이며, 타일 종류는 **월드 좌표 영역(region)** 으로 결정합니다.

관련 구현: `assets/scripts/world/tile-region-field.ts`, `default-world-pipeline.ts`.

## 원칙 1 — 청크와 혼합 경계

1. 청크 **전체가 한 타일 종류**일 수 있다.
2. 청크 **안에 여러 타일 종류가 공존**할 수 있다.
3. 여러 종류가 공존하는 경우는 **해당 종류의 영역 경계에 걸린 청크**에서만 허용한다.
4. 다음을 **둘 다** 만족하면 그 청크는 **해당 종류만** 가진다.
   - **(A)** 청크 상·하·좌·우 **가장자리 한 줄**이 전부 동일 종류
   - **(B)** **이웃 청크와 맞닿는 바깥 한 줄**(월드 좌표)도 전부 동일 종류

해석: 영역 **내부** 청크는 단일 타일, **경계** 청크만 혼합한다.

## 원칙 2 — 군집·최소 크기·곡선

1. 같은 종류는 **서로 붙으려는 경향**이 강하다.
2. 같은 종류의 **연결 성분**은 **최소 32타일**이어야 한다.
3. **연결**은 상하좌우(4-연결) 기준이다.
4. 영역 모양은 **직사각형이 아닌** 랜덤 곡선(유기적 실루엣)이어야 한다.

## 적용 범위

바닥(풀·진흙·물)과 장애물(나무·바위)을 포함한 **모든 지형 타일**에 적용한다.  
콘텐츠(광석·몬스터·NPC 등)는 이 원칙의 대상이 아니다.

## 생성 모델 (구현 계약)

```text
월드 좌표 (wx, wy)
  → 도메인 워프 + 저주파 필드 / 지터 Voronoi
  → 타일 종류 샘플
  → 청크 단위로 (A)(B) 검사 후 내부 단일화
```

- 청크마다 바이옴을 통째로 뽑지 않는다.
- 같은 Seed·같은 월드 좌표는 항상 같은 타일을 낸다 (`Math.random` 금지).
- 평균 영역 크기가 최소 32를 만족하도록 **저주파 FBM(스케일 ≈ 26타일)** 과 **강한 도메인 워프**를 사용한다. Voronoi/청크 격자 정렬을 피한다.

## 시드 호환

이 원칙 도입 이후 **같은 Seed라도 이전 빌드와 지형 모양이 다를 수 있다.**  
저장 모델(Seed + delta)은 유지된다.
